# 🛒 淘宝用户行为数据分析与电商漏斗模型实战

本项目基于淘宝真实用户行为数据集（`UserBehavior.csv`，抽样 100 万行），使用 Python (Pandas, Matplotlib) 进行数据清洗、探索性数据分析（EDA）以及核心电商转化漏斗建模。

## 📊 项目亮点与核心结论
- **数据预处理**：完成时间戳转换、去重、时间序列排序等清洗流程。
- **漏斗转化率分析**：
  - 整体浏览量 (PV) 到收藏、加购、购买的转化链路追踪。
  - 发现了用户在“加购”与“收藏”阶段的转化偏好差异。
- **时间规律挖掘**：分析了用户全天 24 小时的活跃高峰期。

## 🛠️ 技术栈
- **编程语言**：Python
- **核心库**：Pandas, NumPy, Matplotlib
- **工具**：Jupyter Notebook, Git & GitHub
